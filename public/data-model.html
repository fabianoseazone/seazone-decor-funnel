Descrição das Tabelas

🏢 EMPREENDIMENTO
Cada empreendimento imobiliário (ex: Santinho Spot, Batel Spot). Ponto de entrada do fluxo.
PKcodigoIdentificador único
descricaoNome do empreendimento
cidade / estadoLocalização
quantidade_unidadesTotal de apartamentos
📦 PACOTE
Os 5 níveis de decoração disponíveis. Define o padrão de acabamento.
PKcodigoIdentificador único
descricaoEssential / Plus / Premium / HD1 / Ampliada
abreviacaoES / PL / PR / HD1 / AM
🏠 TIPOLOGIA
Combina empreendimento + tipo físico (A, B, C…) + pacote. Define custos e características.
PKcodigoIdentificador único
FKempreendimento_codigo→ Empreendimento
FKpacote_codigo→ Pacote
tipo_letraTipo físico: A, B, C…
num_hospedesCapacidade de hóspedes
decor_valorValor fixo da decoração
adm_percent% taxa de administração
🚪 APARTAMENTO
Cada unidade física (101, 202…). Ligada a um empreendimento e uma tipologia.
PKcodigoIdentificador único
FKempreendimento_codigo→ Empreendimento
FKtipologia_codigo→ Tipologia
apartamento_idNúmero da unidade (101, 202…)
🛋️ PRODUTO
Catálogo completo de produtos (móveis, eletrodomésticos, decoração etc.).
PKcodigoIdentificador único
nomeNome do produto
categoria_codigoCategoria principal
subcategoria_codigoSubcategoria (para filtros)
valorPreço de referência
imagem_urlFoto (Google Drive)
🔗 PRODUTO_TIPOLOGIA
Tabela de junção: lista exata de produtos de cada tipologia, com preço e flag de opcional.
PKcodigoIdentificador único
FKtipologia_codigo→ Tipologia
FKproduto_codigo→ Produto
quantidadeQtd do item no pacote
valor_unitarioPreço neste pacote
item_adicionalfalse = padrão / true = opcional

Fluxo de Consumo no App

🏢

1. Seleciona Empreendimento

Usuário escolhe o empreendimento onde tem o imóvel

SELECT * FROM empreendimento
→
🚪

2. Seleciona Unidade

Filtra apartamentos do empreendimento escolhido

WHERE empreendimento_codigo = X
→
📦

3. Escolhe o Pacote

Mostra todos os pacotes disponíveis para a tipologia física da unidade

WHERE tipo_letra = A AND empreendimento = X
→
🛋️

4. Personaliza Produtos

Lista produtos do pacote. Permite remover padrão ou trocar por similar

WHERE tipologia_codigo = T
→
💰

5. Gera Orçamento

Calcula total: produtos + decor + taxa adm. Gera proposta final

SUM(valor_unitario × quantidade)

Relacionamentos Principais

🏢→🏠
Empreendimento → Tipologia (1:N) Um empreendimento tem várias tipologias (1 por combinação tipo+pacote). Ex: Santinho tem tipologia A-Essential, A-Plus, A-Premium, B-Essential…
🏢→🚪
Empreendimento → Apartamento (1:N) Um empreendimento tem muitos apartamentos. Ex: Santinho tem 200+ unidades (101, 102, 201…)
📦→🏠
Pacote → Tipologia (1:N) Um pacote (ex: Plus) aparece em várias tipologias, uma por empreendimento+tipo físico.
🏠→🚪
Tipologia → Apartamento (1:N) Uma tipologia classifica várias unidades. Todos os aptos do tipo A-Plus compartilham a mesma lista de produtos.
🏠↔🛋️
Tipologia ↔ Produto (N:N via produto_tipologia) Uma tipologia tem muitos produtos; um produto aparece em muitas tipologias. A tabela de junção guarda o preço e a flag de item opcional.
🔑
Chave de negócio: empreendimento + tipo_letra Identifica a "tipologia física" — usada para buscar os pacotes disponíveis de uma unidade e as alternativas de substituição de produto.
